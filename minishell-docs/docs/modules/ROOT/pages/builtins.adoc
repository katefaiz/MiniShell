= Built-in Commands
:description: Reference for all MiniShell built-in commands

MiniShell implements the following built-in commands directly,
without spawning a child process.

== echo

[source]
----
echo [arg ...]
----

Print arguments to standard output separated by spaces, followed by a newline.

[source,bash]
----
echo hello world
# hello world

echo $PWD
# /home/user
----

== cd

[source]
----
cd [directory]
----

Change the current working directory.
If _directory_ is omitted, change to `$HOME`.
Updates the environment variables `PWD` and `OLDPWD`.

[source,bash]
----
cd /tmp
cd          # goes to $HOME
----

== ls

[source]
----
ls [-a] [directory]
----

List directory contents. Defaults to the current directory.

[cols="1,3"]
|===
| Option | Description

| `-a`
| Show hidden entries (names beginning with `.`)
|===

Output is colour-coded: directories in blue, executables in green,
regular files in the default colour.

[source,bash]
----
ls
ls -a /etc
ls /usr/bin
----

== pwd

[source]
----
pwd
----

Print the absolute path of the current working directory.

[source,bash]
----
pwd
# /home/user/MiniShell
----

== exit

[source]
----
exit
----

Terminate the shell immediately with exit status 0.

== type

[source]
----
type name
----

Describe how _name_ would be interpreted: reports whether it is a shell
built-in or prints the full path found in `$PATH`.

[source,bash]
----
type echo
# echo is a shell builtin

type gcc
# gcc is /usr/bin/gcc
----

== read

[source]
----
read
----

Read a single line from standard input and print it back.

[source,bash]
----
read
hello there
# hello there
----

== true

Return exit status 0 unconditionally.
Useful as a condition in `while` loops.

== false

Return exit status 1 unconditionally.

== Logical negation

Prepending `!` to any command inverts its exit status
(0 becomes 1, non-zero becomes 0):

[source,bash]
----
! false      # exit status 0
! true       # exit status 1
! (( 1 > 2 ))  # exit status 0 (because 1 > 2 is false)
----

== Exit status table

[cols="1,3"]
|===
| Status | Meaning

| 0
| Success

| 1
| General error (bad argument, command failed, etc.)

| 127
| External command not found
|===
