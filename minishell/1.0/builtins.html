Built-in Commands

MiniShell implements the following built-in commands directly, without spawning a child process.

echo

echo [arg ...]

Print arguments to standard output separated by spaces, followed by a newline.

echo hello world
# hello world

echo $PWD
# /home/user

cd

cd [directory]

Change the current working directory. If directory is omitted, change to $HOME. Updates the environment variables PWD and OLDPWD.

cd /tmp
cd          # goes to $HOME

ls

ls [-a] [directory]

List directory contents. Defaults to the current directory.

Option Description

-a

Show hidden entries (names beginning with .)

Output is colour-coded: directories in blue, executables in green, regular files in the default colour.

ls
ls -a /etc
ls /usr/bin

pwd

pwd

Print the absolute path of the current working directory.

pwd
# /home/user/MiniShell

exit

exit

Terminate the shell immediately with exit status 0.

type

type name

Describe how name would be interpreted: reports whether it is a shell built-in or prints the full path found in $PATH.

type echo
# echo is a shell builtin

type gcc
# gcc is /usr/bin/gcc

read

read

Read a single line from standard input and print it back.

read
hello there
# hello there

true

Return exit status 0 unconditionally. Useful as a condition in while loops.

false

Return exit status 1 unconditionally.

Logical negation

Prepending ! to any command inverts its exit status (0 becomes 1, non-zero becomes 0):

! false      # exit status 0
! true       # exit status 1
! (( 1 > 2 ))  # exit status 0 (because 1 > 2 is false)

Exit status table

Status Meaning

0

Success

1

General error (bad argument, command failed, etc.)

127

External command not found
