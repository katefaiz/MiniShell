Variables & Arithmetic

Shell Variables

Assignment

Variables are set with plain assignment — no spaces around =, no $ prefix:

name=Alice
count=0
greeting=hello

Expansion

Use $varname to substitute a variable’s value anywhere in a command:

echo $greeting $name
# hello Alice

cd $HOME

Undefined variables expand to the empty string.

Arithmetic Expansion

The syntax $expr evaluates an integer expression and substitutes the result inline.

Supported operators

Operator Description

+

Addition

-

Subtraction

*

Multiplication

/

Integer division

%

Modulo (remainder)

Examples

echo $((3 + 4))
# 7

echo $((10 % 3))
# 1

x=5
echo $((x * 6))
# 30

i=0
i=$((i + 1))
echo $i
# 1
Each expression supports exactly one binary operation. Nested expressions like $1 + 2 + 3 are not supported; use intermediate variables instead. 
# Workaround for chained arithmetic:
a=$((1 + 2))
b=$((a + 3))
echo $b
# 6

Arithmetic Conditions

The syntax expr evaluates a comparison and returns exit status 0 (true) or 1 (false). Used as the condition in if and while.

Supported comparison operators

Operator Description

==

Equal

!=

Not equal

<

Less than

>

Greater than

<=

Less than or equal

>=

Greater than or equal

Negation

Prefix the expression with ! to invert the result:

(( ! x == 0 ))   # true when x is not 0

Examples

(( 3 < 5 ))      # exit status 0 (true)
(( 10 == 9 ))    # exit status 1 (false)

x=7
(( x >= 5 ))     # exit status 0 (true)
(( x != 7 ))     # exit status 1 (false)
